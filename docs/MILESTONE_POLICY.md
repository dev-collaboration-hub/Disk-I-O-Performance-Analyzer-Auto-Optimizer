# Milestone Policy

The active scratch-rebuild milestones are S0–S11.

The former M1–M10 milestone sequence belongs to the completed v1.0.0 cycle and must not be used as evidence that any scratch-rebuild milestone is complete.

When a scratch milestone completes, record:

- implementation scope
- tests and validation evidence
- capability unlocked
- known limitations
- next milestone dependency

Do not mark a milestone complete because equivalent behavior existed in the legacy implementation.
